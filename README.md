# a11yci-scratch

End-to-end test bed for [A11yCI](https://github.com/HoneyForge-LLC/a11yci).

`index.html` (served via GitHub Pages) contains **deliberate** WCAG failures —
missing alt text, an unlabeled input, a nameless button, low-contrast text, a
nameless link — so PR scans have deterministic violations to report.

Test change to trigger the A11yCI check.
